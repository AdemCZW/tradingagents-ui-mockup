# TradingAgents UI mockup

A single-file, offline HTML mockup of a multi-agent trading analysis dashboard: setup wizard, live run dashboard and final report page.

- All data is made up for demonstration. Not investment advice.
- Unofficial design mockup inspired by the open-source TradingAgents CLI (TauricResearch/TradingAgents). Not affiliated with it.
- Open `index.html` directly; deep links `#v1`, `#v2`, `#v3` jump to each screen.
